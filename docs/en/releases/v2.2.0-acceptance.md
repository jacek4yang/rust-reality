## Product contract

| Direction | Status |
| --- | --- |
| rust-reality Client ↔ rust-reality Server, XUDP over Direct, NXR, and Handoff | **Required** |
| Unmodified stock Xray Client → rust-reality Server (VLESS+REALITY+Vision+XUDP) | **Required** ingress |
| rust-reality Client → stock Xray Server | **Not required** (ADR 0059) |

XUDP carries UDP datagrams inside REALITY + Vision. It is **not** native QUIC
transport and **not** MASQUE. Server UDP egress is Direct, NXR, or Handoff.
Block fails closed. The origin echo in guest qualification observes the landing
listener address, because NXR and Handoff bind egress UDP there.

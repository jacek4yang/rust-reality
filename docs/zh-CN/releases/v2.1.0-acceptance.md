## 产品合约（已核实）

| 方向 | 状态 |
| --- | --- |
| rust-reality Client ↔ rust-reality Server（TCP Vision + UDP/XUDP，`allowUdp443`） | **必需** |
| 未修改 stock Xray Client → rust-reality Server（VLESS+REALITY+Vision+XUDP） | **必需** 入向 |
| rust-reality Client → stock Xray Server | **不要求**（ADR 0059） |

XUDP 在 REALITY + Vision 内承载 UDP 数据报。**不是**原生 QUIC，**不是**
MASQUE。服务端 UDP 出站仅 **Direct**；NXR / Handoff / Block 在 Keep 改写上失败关闭。

## 性能诚实性

- v2.1.0 **不做**普遍加速声明。
- UDP 证据是回环单数据报 RTT（含 A/A 噪声），不是互联网吞吐。
- 受保护 TCP 非回归继续由 Exact-head Native（全量门禁 + 600s 矩阵）与 Frozen 承担。
- 可选 Xray Client→RR UDP 对比仅作诊断。

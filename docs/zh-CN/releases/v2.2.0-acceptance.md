## 产品合约

| 方向 | 状态 |
| --- | --- |
| rust-reality Client ↔ rust-reality Server，XUDP 经 Direct、NXR、Handoff | **必需** |
| 未经修改的 stock Xray Client → rust-reality Server（VLESS+REALITY+Vision+XUDP） | **必需**入向 |
| rust-reality Client → stock Xray Server | **不要求**（ADR 0059） |

XUDP 在 REALITY + Vision 内承载 UDP 数据报。它**不是**原生 QUIC，也**不是**
MASQUE。服务端 UDP 出站为 Direct、NXR 或 Handoff。Block 失败关闭。访客资格中
源回声看到的是落地监听地址，因为 NXR 与 Handoff 把出站 UDP 绑定在该地址上。
